# YT Transcript

Локальный сайт: вставляешь ссылку на YouTube → получаешь расшифровку.

## Запуск (macOS)
```bash
cd yt-transcript
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
python app.py
```
Браузер откроется сам на http://127.0.0.1:8765

## Что умеет
- ссылки любого вида: watch, youtu.be, shorts, live, просто ID
- выбор дорожки (ручные/авто) и автоперевод на любой язык
- встроенный плеер: клик по строке — перемотка, текущая строка подсвечивается
- режимы «Строки» / «Абзацы», вкл/выкл таймкоды
- поиск с подсветкой, Enter / Shift+Enter — по совпадениям, `/` — фокус в поиск
- экспорт: TXT, Markdown (таймкоды-ссылки на видео), SRT, JSON, копирование
- `?v=ID` в адресе — закладка сразу на ролик

## Если YouTube блокирует
При ошибках `RequestBlocked` / `IpBlocked` YouTube режет запросы с твоего IP
(часто бывает с VPN/облачных IP). Выключи/смени VPN или попробуй позже.
